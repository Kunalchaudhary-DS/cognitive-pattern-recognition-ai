# Cognitive Pattern Recognition System

An AutoML backend that lets users upload a CSV dataset, automatically preprocesses it, trains multiple ML models, and returns patterns, clusters, feature importances, and intelligent insights.

---

## Getting Started

### 1. Clone and set up a virtual environment

```bash
git clone <your-repo-url>
cd cognitive-pattern-recognition

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the server

```bash
uvicorn app.main:app --reload
```

Visit `http://127.0.0.1:8000` to open the app.  
Visit `http://127.0.0.1:8000/docs` for the interactive API docs (auto-generated by FastAPI).

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Serves the frontend |
| GET | `/demo-datasets/` | Lists all available demo datasets |
| POST | `/upload/` | Upload a CSV file |
| POST | `/load-demo-dataset/` | Load a built-in demo dataset |
| POST | `/feature-importance/` | Get correlation-based feature importance |
| POST | `/preprocess/` | Run full preprocessing pipeline |
| POST | `/train/` | Train all models, return results + best model |
| GET | `/dashboard-data/` | Full analysis: patterns, clusters, insights |

## Typical Workflow

1. Upload a CSV → `/upload/`
2. Check feature importance → `/feature-importance/`
3. Preprocess with chosen target → `/preprocess/`
4. Train all models → `/train/`
5. Get full dashboard analysis → `/dashboard-data/`
